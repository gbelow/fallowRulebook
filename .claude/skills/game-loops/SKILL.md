# Game Loops Quick Reference

Source of truth: `play.tex`. Re-read it if exactness matters or if wording
looks like it may have changed — this is a compressed map, not a replacement.

## Four loops

- **Big loop** — campaign framing: dungeon crawl/heist (life is cheap,
  characters are numbers), arena (PvP war-game), or story (named characters,
  backstories, objectives). All three run on the same combat/exploration/
  social toolkit — nothing forces a table into one mode.
- **Scene** — moment-to-moment action where players describe precisely what
  their character does. Uses the grid whenever combat is possible; other
  modes can be eyeballed. 1 grid space ≈ 1 AP of movement ≈ 1m diameter;
  larger creatures take more spaces.
- **Exploration** — point-crawl between nodes, resource-managed (hunger,
  thirst, exhaustion) in 4-hour blocks per day. Deliberately harsh — designed
  to force dramatic trade-off decisions, not a death march.
- **Downtime** — growth between ventures: skills, abilities, contacts, gear,
  via XP, karma, money, and time.

## Four scene modes (bleed into and hand off to each other)

**Combat** — the game's main tactical puzzle; least room for GM adjudication,
most for build/skill mastery, "much like a puzzle or chess game." Rounds ≈3s,
turn order is "first to ask, first to play" (contestable). Driven by AP and
stamina economy. Objectives: Defeat / Defend / Defeat Target /
Escort-Kidnapping.
Disengagement options (the bridges to other modes):
  - **Negotiation** — at the morale test; can lead to capitulation or truce.
  - **Escape** — one side runs; starts a chase scene.
  - **Capitulation** — each character can stand down before dying; combat
    ends when a round starts with one whole side down; bleeding punishes
    fighting on past that point.

**Chase** — fighting-on-the-run and escape; distance tiers gate which actions
are available. Stamina, gear burden, and movement speed decide who catches
whom; a party can sacrifice its slowest member to save the rest. The escaping
side picks the destination, so it can angle for advantageous terrain
(co-creation tools support this) — a chase can restart combat elsewhere.
Objectives: Reaching safety / Hiding / Outrunning / Separating / Catching /
Fight on the run.

**Social** — rules are intentionally light so acting isn't shut down, but
skill still matters (Interpretation bonus, Contacts) so it isn't pure
free-form. Stating intent flatly instead of acting it out forgoes the GM's
interpretation bonus. Needs an irreversible consequence per action, or the
test can just be repeated indefinitely. Common actions: Performance,
Persuasion, Negotiation, Seduction, Intimidation.

**Stealth** — player-described "stealth events" set the DL; players are
encouraged to ask leading questions ("is there something to hide behind?")
to shift cognitive load onto themselves — GM has final say and should cap
abuse. Guidelines, not fixed modifier tables, by design (avoids simulation
bloat); a GM who wants a pre-defined puzzle can still build one. Can run
without the grid unless combat risk is present; failure can trigger any other
mode. Objectives: Stealth (go unnoticed) / Theft / Sabotage.

## Grid

Required for any scene with combat risk; other modes can be estimated. Hex
(recommended) or square. 1 space ≈ 1 AP of movement ≈ 1m diameter; larger
creatures take more spaces. Positioning must be agreed by everyone at all
times — approximating it devalues build choices tied to the action economy.
